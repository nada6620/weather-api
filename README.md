# Weather API

A REST API that provides current weather information for a given city.

## Features

- Get weather information by city
- Redis caching
- External weather API integration
- Error handling
- Rate limiting

## Technologies

- Node.js
- Express.js
- Redis
- Visual Crossing Weather API
- Axios
